# Reference assets

## black-direction-2026-09.webp

The approved visual direction for Quiet Material 1.4 and the authority for the
black/graphite/white language: pure-black canvas, matte near-black panels,
restrained neutral edges, white selection and primary-action treatments,
consistent rounded rectangles and pill controls, white headings with
neutral-gray supporting text, and generous negative space.

- Provenance: supplied by the repository owner on 2026-09-19 as the approved
  direction for this migration. It is a concept board, not a screenshot of a
  running build, and not a photograph of a shipped product.
- Status: current approved reference. It supersedes
  `../approved-concept.png`, which is retained as a historical reference for
  the 1.0-1.3 charcoal appearance.
- Scope: the visual language is normative. The device bezels, planetary
  wallpaper, mountain footer, demo wordmark, app names and third-party app
  icons in the board are illustration only. They are not design tokens, not
  component requirements, and not features of this design system.
- Colour values in `tokens/quiet-material.tokens.json` are deliberate design
  choices made for this migration. They are not sampled pixel values from this
  image, and the board is not a colour-accurate source.
- The on-screen keyboard shown in the third panel is an operating-system
  surface. This repository does not implement, restyle or simulate it.

See `docs/foundations.md` for the resulting token values and
`docs/validation.md` for how implementation screenshots were compared with
this reference.
